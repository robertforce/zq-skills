# 论文图片工作流

## 目标

把论文图片当作证据，而不是装饰。完成“发现—理解—选择—导出—插入—核对”六步，并保留来源映射。

## 建立资产清单

为每张候选图片或表格记录：

- `asset_id`：稳定的本地标识，例如 `fig-03`。
- `source_label`：论文中的 Figure、Table 或 Appendix 编号。
- `source_page`：对应论文版本中的页码。
- `caption`：原始图注或表注。
- `type`：`method_diagram`、`result_chart`、`ablation`、`table` 或其他。
- `status`：`ready`、`missing`、`unreadable` 或 `conflict`。
- `supports`：它支持的阅读记录结论或证据 ID。

文本抽取中只有图片占位符时，不能认为该章节没有内容。回到原始 PDF 页面或论文源文件检查。

## 理解图片

同时查看原图、图注、前后正文和附录说明：

- 结果图：确认坐标轴、指标方向、单位、图例、数据集、基线、误差线和统计信息。
- 表格：确认行列含义、最优值标记、相对与绝对提升、离线与在线指标。
- 方法图：确认输入输出、数据流、训练路径、推理路径和模块职责。
- 消融图：确认具体移除了什么、控制变量是否成立、下降是否足以支持收益归因。

OCR 结果必须与视觉内容和上下文交叉核对。无法辨认的数字保持未知，不根据邻近文本猜测。

## 选择图片

每张入选图片必须服务于文章中的一个明确问题：

- 方法为什么这样设计？
- 论文的主要收益是否真实？
- 收益可能来自哪个模块？
- 论文的局限或异常现象是什么？

通常优先选择方法总览、关键结果和有解释力的消融。默认 2 到 4 张只是编辑参考，不是配额；论文信息密度低时可以更少。

排除装饰图、重复表达同一结论的图、无法解释的复杂图、无法确认指标或单位的图，以及正文不会分析的图。

## 导出图片

1. 有论文源码时优先使用原始图片文件，保留矢量版本作为源文件。
2. 只有 PDF 时，从对应页面高分辨率渲染后精确裁剪；避免使用二手文章截图。
3. 不修改数据、坐标轴或图例，不移除水印。重新绘制方法示意图时明确标注“根据论文重绘”。
4. 将原始提取图片保存到 `source/assets/`，使用稳定文件名，例如 `source/assets/fig-03-main-result.png`。
5. 记录原论文版本、页码、图号和本地文件路径。
6. 核查论文许可和出版方要求；许可不明确时保留为内部草稿并要求人工确认。

如果导出失败，不创建伪造图片或断链。将资产状态设为 `missing` 或 `unreadable`，阻止稿件进入可发布审核。

完整中文译稿直接引用 `../source/assets/`。目标文章只把最终入选图片复制到 `article/assets/`，避免发布草稿依赖译稿目录；复制后核对内容与原始提取图片一致。

## 插入 Markdown

图片前说明图片与当前问题的关系，图片后解释图中直接呈现的信息。证据充分性、统计缺口和图片未能回答的问题集中到文章末尾判断章节：

```md
图 3 对比了不同融合方式下的线上指标，用于观察自适应权重对多目标平衡的影响。

![不同融合方式的在线指标对比](./assets/fig-03-main-result.png)

*图 3：不同融合方式的在线指标对比。来源：论文 Figure 3，第 7 页。*

图中静态权重组的观看时长上升，同时部分互动指标下降；自适应权重组的各项指标变化更均衡。
```

替代文本要描述图片信息，不写“图片”“截图”等无意义内容。图注包含论文图号和页码；需要时增加论文链接。不要把证据定位只藏在文件名中。

## 图片门禁

出现以下任一情况时，审稿建议必须为退回修改：

- 结果章节只有图片占位符，原图未获取。
- 关键表格无法辨认列名、单位或数值。
- 图片解读与正文或附录冲突，尚未人工确认。
- 图注缺失导致无法确定数据集、指标或基线。
- 正文引用图片结论，但没有图号、页码或证据映射。
- Markdown 图片路径不存在。
- 译稿遗漏原论文中的图片或表格，只保留文本占位符。

禁止交付只有图片、没有解释文字的结果章节。

## 知乎排版

本地 Markdown 保持正常的图片块和相对路径。将批准稿填入知乎时，按 [zhihu-delivery.md](zhihu-delivery.md) 上传图片并清理编辑器额外生成的空段。

知乎发布前逐张确认：

- 图片数量和顺序与批准稿一致。
- 图片前一段是解释该图用途的正文，图片后一段是对应图注。
- 图片两侧没有空的普通段落。
- 编辑器中没有上传失败、上传中或重试占位符。
