# 探脉 DeepTrace

> 从一个说不清的感觉，找到它背后的结构。

一个 AI Skill（Claude Code 等 Agent 通用）。你丢给它一个还没成形的直觉、感受、现象、疑惑、不舒服、情绪或阅读划线，它一次性帮你深挖到底：点破你真正碰到的问题，给它起名、找到理论祖先，升级你自己的模型，用多个学科的理论和真实文献解释，摆出反例和争议，最后回到你的经历，给出能照做的用法。

你看完再判断："不对""对了一半""更像第三种"——然后继续下一轮。

## 它和"深度研究"有什么不同

普通调研从一个清楚的问题出发。探脉可以从"我也说不清自己在想什么"出发。

它服务的是这样一个人机递归循环：

```text
人：直觉、感受、思考、洞察、事实、现象、问题、疑惑、不舒服、情绪、好奇、阅读划线……
  ↓
AI：深度分析、思考、拓展          ← 探脉负责这一步
  ↓
人：看到结果，修正自己的思考、加深判断，或者引出更多好奇
  ↓
AI：继续思考和拓展
  ↺
```

探脉负责中间那一步。它一次给足，不先反问你：你的判断，发生在看到丰富的展开之后。

## 你会得到什么

一次探脉的默认结构：

- **一句点破**：你摸到的到底是什么，比你原来的说法深一层
- **工作名 + 理论祖先**：给这个现象起名，找到历史上谁提过相近的思想
- **电梯解释**：普通人也能听懂的版本
- **暴论**：推到极致、可以直接传播的判断
- **升级你的模型**：把你原来的想法画出来，指出缺了什么，给出升级版
- **为什么成立**：3-5 层理论，来自至少三个学科，每层都回到你的经历
- **机制、更深一层、对照表**
- **反面与争议**：什么条件下不成立
- **一个启发式公式**（注明不是学术公式）
- **回到你、最容易犯的错、怎么用**（附可复制的提示词）
- **总结和金句**
- **参考文献**：Chicago 格式，每条注明"它在这次论证里说明了什么"
- **下一步**：把这次成果推进到你的文章、书、课程或产品里

## 两条硬规矩

- **只引用当次真实查到的文献。** 查不到的年份、DOI 就空着，不编。
- **必须有"反面与争议"。** 目标是把你的直觉 A 升级成更准确的 A′，而不是证明你是对的。

## 怎么触发

直接说出你的感觉就行，比如：

- "我有种感觉但说不清……"
- "这个和 XX 好像有关系"
- "我最近一直发现一个现象……"
- "这里让我不舒服，但不知道为什么"
- "有没有理论能解释这个？"
- 或者直接说："探脉：……"

## 安装

**方式一：让 AI 帮你装**

打开 [木妈AIdea Skill 下载库](https://mumaaidea.com/skills)，找到「探脉」，复制安装指令发给你的 AI 助手。

**方式二：手动安装（Claude Code）**

```bash
git clone https://github.com/vickysy/deeptrace.git ~/.claude/skills/deeptrace
```

探脉需要联网搜索能力（WebSearch / WebFetch）来查证文献。没有联网时，它只提理论名称和代表人物，不列文献条目。

## 可选：接上你的知识库

在 `SKILL.md` 的"第 0 步"里填上你的知识库路径（比如 Obsidian vault），探脉会先在里面找和这次信号相关的经历和笔记，把解释落到你自己身上。每次探脉的结果也可以存成"探脉卡"放回知识库，以后的探脉会把不同时间挖到的东西连起来。
